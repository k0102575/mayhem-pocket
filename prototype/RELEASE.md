## 비교 테스트용 C# 시제품

**Node 없는 실행 방식과 배포 용량을 비교하기 위한 테스트용입니다. 전체 기능을 지원하는 정식 버전의 대체품은 아닙니다.** GitHub 일반 Release로 게시하되 최신 정식 버전 v0.1.5는 유지합니다.

- [기존 Node 버전 v0.1.5](https://github.com/k0102575/mayhem-pocket/releases/tag/v0.1.5)와 이 릴리스의 `mayhem-pocket-csharp-preview.zip`을 각각 다른 폴더에 풀어 비교해 주세요.
- `Source code` 대신 실행용 ZIP을 받고, 압축을 모두 푼 뒤 `Mayhem Pocket.exe` 또는 `실행.cmd`를 실행합니다. 화면 종료·트레이 메뉴·`종료.cmd`로 종료할 수 있습니다.
- Node 설치나 별도 런타임 파일 없이 Windows 10/11 기본 .NET Framework를 사용합니다. .NET Framework 기능이 비활성화된 PC에서는 실행할 수 없습니다.

## 지원하는 기능

- 기존 화면과 저장된 챔피언 목록·증강·빌드·증강 도감 조회
- 기존 `문서/mayhem-pocket`의 캐시와 이미지를 읽기 전용으로 사용
- 설정은 별도 `문서/mayhem-pocket-csharp-preview`에 저장하며 기존 API 키와 설정은 변경하지 않음
- 트레이와 로컬 서버를 하나의 프로세스에서 실행, 중복 실행 방지·정상 종료

## 지원하지 않는 기능

**API 다운로드·최신 버전 확인·키 등록·전체 증강 수집·이미지 재다운로드는 지원하지 않습니다.** 기존 캐시가 없으면 데이터가 없는 상태로 표시됩니다. 정식 버전에서 먼저 데이터를 받은 뒤 비교해 주세요. 다운로드 버튼 일부는 기존 화면에 남아 있으며 요청 시 미지원 안내를 표시합니다. 시제품은 외부 API를 호출하지 않습니다.

간단한 HTTP 서버는 로컬 시제품 검증용입니다. 정식 전환을 위해서는 다운로드·할당량·취소·버전 변경 처리와 서버 구현의 추가 검증이 필요합니다. 런타임 메모리와 성능은 측정하지 않았습니다.

## 크기 비교 및 검증

첨부한 `prototype-comparison.md`와 `prototype-comparison.json`에 이번 ZIP과 v0.1.5의 크기·파일 수 및 Windows 검증 결과를 기록했습니다. 이 시제품은 조회용이므로 기능이 완전히 동등한 비교는 아닙니다.

Windows CI에서 한글·공백 경로 실행, 기존 캐시 조회, 설정 저장·재실행, 웹·트레이 종료, 중복 실행, 포트 충돌, 강제 종료 후 재시작, 기존 키·설정 무변경을 통과한 뒤 게시합니다. 실제 Windows PC에서 트레이·브라우저 표시와 사용성을 비교해 주세요.
