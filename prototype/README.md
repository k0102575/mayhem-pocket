# C# 서버 시제품

정식 버전이 아닌 용량·실행 방식 검증용 시제품입니다. Windows 10/11의 기본 .NET Framework를 사용하며 Node/Python/.NET 런타임을 별도 포함하지 않습니다. .NET Framework 기능이 비활성화된 PC에서는 실행할 수 없습니다.

Mayhem Pocket.exe 또는 실행.cmd로 시작하고, 화면 종료·트레이 종료·종료.cmd로 종료합니다. 기존 버전과 별도 데이터 폴더 및 실행 식별자를 사용합니다.

## 지원 범위

- 기존 React 화면, 저장된 챔피언 목록·상세·빌드·증강 도감 조회
- 기존 문서/mayhem-pocket의 캐시 및 이미지를 읽기 전용으로 조회
- 시제품 설정은 문서/mayhem-pocket-csharp-preview에 별도 저장
- 로컬 서버와 트레이를 같은 프로세스에서 실행, 중복 실행 방지 및 정상 종료

API 다운로드·최신 버전 확인·키 등록·전체 증강 수집·이미지 재다운로드·예전 폴더 캐시 이전은 지원하지 않습니다. 기존 캐시가 없으면 데이터가 없는 상태로 표시됩니다. 시제품에서 다운로드 버튼을 누르면 미지원 안내를 표시합니다. API 키는 읽거나 변경하지 않으며 외부 API 호출 비용은 발생하지 않습니다.

포함된 웹 화면은 기존 정식 버전 기반입니다. 다운로드 같은 미지원 기능의 화면 버튼이 남아 있으며, 서버에서 요청을 거부합니다. 실제 API 수집·할당량·취소·버전 변경 처리까지 동등하게 구현한 결과가 아니므로, 용량 감소만으로 정식 버전 교체를 결정하지 않습니다.

이 시제품의 간단한 HTTP 구현은 로컬 검증용입니다. 정식 전환 시 유지보수 가능한 HTTP 구현과 보안·동시 요청·비정상 종료 복구 검증을 추가로 수행해야 합니다. 외부 네트워크에 공개하지 않습니다.
