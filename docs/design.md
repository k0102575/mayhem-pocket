# Mayhem Pocket 설계

## 목적과 사용 환경

Windows 10, RAM 16GB, Chrome, 4K 화면·150% 배율의 단일 모니터에서 게임 중 잠깐 검색하는 개인용 아수라장 참고 도구다. 광고, 추적 스크립트, 게임 연동, OCR, 오버레이 없이 필요한 데이터만 표시한다. 코드는 공개하고 API 키와 내려받은 데이터·이미지·개인 백업은 공개하지 않는다.

## 기술 구성

- React, TypeScript, Vite
- shadcn/ui, Tailwind CSS, 다크 테마
- Node.js, Fastify 로컬 서버
- 버전별 JSON 파일 및 이미지 캐시, 첫 버전은 DB 불필요
- Windows 배포본에 호환되는 Node 런타임 포함. 개발·빌드는 Node 설치 환경에서 수행한다.
- 개발 중 Vite 서버와 API 서버를 사용하고 배포 시 Fastify가 빌드된 정적 화면과 API를 함께 제공한다.

## 화면과 기능

첫 화면은 검색창, 즐겨찾기, 최근 조회, 챔피언 티어 목록으로 구성한다. 이름·초성·영문 별칭 검색을 지원한다. 실제 Chrome CSS viewport에 맞춰 반응형으로 배치하며 물리 해상도 3840px를 화면 너비로 가정하지 않는다.

챔피언 상세는 요약과 증강/빌드 탭으로 구성한다. 마지막 챔피언·탭·필터를 기억한다. 검색 단축키 `/`는 입력창 바깥에서만 동작하며 Escape로 검색을 해제한다. 검색과 필터링은 저장된 데이터를 사용한다.

증강은 API rank 오름차순이 기본이다. 등급 필터, 이름·초성 검색, 승률순 전환을 제공한다. 승률, 표본 수, 출처를 함께 표시한다. 미제공 값은 0으로 바꾸지 않고 정보 없음으로 표시한다. 승률순은 유효 값만 정렬하고 누락 값은 마지막에 둔다.

빌드는 사용 빈도순을 기본으로 한다. 빌드 유형별 코어 아이템, 후속 아이템, 소환사 주문, 스킬 순서를 표시한다. 승률 정렬 시 표본 수를 함께 노출한다. 일반 칼바람 빌드도 참고 자료로 허용한다는 사용자 결정을 반영한다. 아수라장 전용 통계라고 단정하지 않는다.

## 데이터와 검증

ARAMGG 한국어 API를 사용한다. 챔피언 승률, 증강 추천 순위, 업로드 표본 승률, 빌드는 출처가 다를 수 있으므로 provenance를 보존한다. tier 숫자의 의미는 별도 확인 전 임의로 S~D로 변환하지 않는다. 패치는 원본 표기를 보존한다.

블라디미르 상세 실측: 증강 120개, 조합 5개, 빌드 3개. 최상위 items는 비어 있어도 builds 안에 아이템이 있다. 일부 winRate는 음수이며 일부 값은 wins/games와 일치하지 않는다. 범위를 벗어난 값을 승률로 노출하거나 wins/games로 조용히 대체하지 않는다. 불일치는 기록하고 해당 승률은 숨긴다. 비교 시 API 반올림을 고려한다.

원시 champion-augments/8.json도 1 credit으로 확인했다. 응답은 4열 tuple이고 stats_json에 augments, augment_trios 등이 있다. 상세 응답의 builds까지 이 원시 요청에 포함된다고 가정하지 않는다.

## 다운로드와 캐시

config.json은 무료로 버전을 확인한다. 실행할 때 한 번 확인하고 상시 폴링하지 않는다. 갱신은 사용자 버튼으로 수행하며 버전과 예상 credits를 표시한다.

전체 원시 증강 통계와 챔피언·증강 목록은 문서상 173명 기준 175 credits다. 챔피언 수에 따라 비용을 계산한다. 빌드 상세는 조회한 챔피언부터 2 credits로 받아 캐시하는 방식을 기본으로 한다. 무료량 안에 전체 상세가 들어간다고 가정하지 않는다. 동일 버전 상세는 재사용한다.

실제 credit 응답 헤더로 잔량을 갱신한다. 로컬 사용 기록은 계정 전체 잔량의 보장이 아니므로 헤더가 우선이다. 초기 수집은 하루 예산 일부를 상세 조회용으로 남기고 재개 가능하게 한다. 분당 60회 이내로 순차·제한된 다운로드를 수행한다. 429면 중단하고 다음 초기화 이후 수동 재개한다. 자동 추가 결제·유료 전환 기능은 구현하지 않는다.

다운로드는 임시 디렉터리에 저장하고 구조 검증 후 현재 버전 포인터를 교체한다. 실패해도 기존 캐시를 유지한다. 버전이 바뀌었을 때 이전 상세는 구버전 표시를 붙여 볼 수 있게 한다. 데이터가 없으면 다운로드 안내를 표시한다. 오프라인에서도 캐시 조회는 가능하다.

아이콘은 화면에 필요한 것부터 내려받아 파일로 캐시한다. 작은 크기로 표시하고 지연 로딩하며 실패 시 기본 아이콘과 이름을 보여준다. 외부 이미지 URL은 신뢰할 수 있는 HTTPS 호스트 목록으로 제한하고 임의 URL 프록시로 사용되지 않게 한다.

## 쉽게 실행하고 종료하기

Windows 배포본의 실행.cmd 더블클릭으로 내장 Node 서버를 시작하고 기본 브라우저를 연다. 중복 실행 시 기존 정상 서버를 확인하고 화면만 연다. 포트 충돌 시 다른 빈 loopback 포트를 선택한다. Chrome 미설치·경로 차이는 기본 브라우저 열기로 대응한다.

화면 상단에 명확한 종료 버튼을 둔다. 종료하면 진행 중 갱신을 안전하게 취소하고 서버 프로세스를 종료한다. 브라우저 탭 자동 닫기는 보장하지 않으며 화면에 종료 완료를 표시한다. 브라우저를 먼저 닫아도 종료할 수 있도록 종료.cmd도 함께 배포한다. 실행 창을 닫는 동작의 프로세스 정리도 Windows에서 검증한다.

종료 명령은 이 앱이 생성한 프로세스만 대상으로 한다. node.exe 전체 종료 같은 방식은 사용하지 않는다. 저장한 PID만 믿지 않고 앱 인스턴스 식별과 실행 경로를 확인한다. 배포 폴더 이동, 중복 실행, 남은 잠금 파일을 처리한다.

## 보안과 공개 저장소

서버는 127.0.0.1에만 바인딩한다. 브라우저 번들·응답·로그에 API 키를 포함하지 않는다. VITE_ 환경변수에 키를 넣지 않는다. 갱신·종료 등 변경 요청은 POST로 처리하고 Origin/Host 및 세션 토큰을 검증해 다른 웹사이트에서 로컬 서버를 조작하지 못하게 한다. API 키는 .env에서만 읽는다.

원격 설명에 포함된 HTML 유사 태그는 그대로 삽입하지 않고 안전한 텍스트/허용된 렌더링으로 처리한다. 다운로드 데이터·아이콘은 Git 제외, .env.example만 공개한다. README에 ARAMGG 출처와 Riot 비공식 고지를 포함한다. 공개 재배포 권한을 포괄적으로 확보했다고 표현하지 않는다.

## 완료 검증

- 블라디미르 기준 추천 순위, 필터, 빌드와 데이터 출처 확인
- 누락·음수·불일치 승률 처리 확인
- 캐시가 있으면 조회 중 API 요청이 발생하지 않는지 확인
- 오프라인·429·중간 실패 시 캐시 보존과 재개 확인
- Windows 10에서 런타임 별도 설치 없이 실행, 중복 실행, 종료 확인
- Chrome 150% 배율과 작은 창에서 검색·탭·아이콘 가독성 확인
- 서버 및 Chrome 탭 메모리를 구분해 유휴·조회 중 사용량 측정. 측정 전 절감 수치를 약속하지 않는다.

## 구현 순서

1. 서버·화면 골격, 데이터 계약 및 이상값 처리
2. 버전 캐시·credit 관리·재개 가능한 다운로드
3. 챔피언 검색·증강 순위·빌드 화면
4. 이미지 캐시·즐겨찾기·최근 조회
5. Windows 실행·종료·런타임 포함 배포 및 검증
