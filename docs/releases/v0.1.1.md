## 변경 사항

- 다운로드 시각, 통계 기준일, 제공자 데이터 생성 시각을 구분해 표시합니다. 기존 캐시에 다운로드 시각이 없으면 `미기록`으로 표시합니다.
- 서버의 최신 데이터 버전과 업데이트 여부, 무료 버전 재확인 버튼을 추가했습니다.
- 같은 버전의 챔피언 목록과 상세는 재다운로드하지 않습니다. 전체 증강 수집 전에 예상 credits를 안내합니다.
- 새 상세가 이전 증강 캐시에 가려지던 문제를 수정했습니다. 최신 증강과 이전 빌드의 버전이 다르면 이전 빌드를 별도 표시해 유지합니다.
- 전체 수집 시 목록과 증강 데이터의 버전을 맞추고, 수집 중 버전 변경이나 할당량 제한이 발생하면 기존 캐시를 보존합니다.
- 수집 중 검색어가 초기화되던 문제와 취소 후 대기 중인 요청이 실행되는 문제를 수정했습니다.
- API 키별로 credits 기록을 구분하고 마지막 잔량 확인 시각을 표시합니다.
- 즐겨찾기, 최근 조회, 필터 설정을 로컬 파일에 저장해 접속 포트가 바뀌어도 유지합니다.
- 아이콘 재다운로드 기능과 원시 응답의 증강 조합 표시를 추가했습니다.
- 빌드 정렬 안내 문구를 실제 선택한 정렬 방식과 일치시켰습니다.
- Windows ZIP의 한글·공백 경로, 실행·중복 실행·종료 스크립트 검증을 확대했습니다.

## 검증

- 캐시 버전 선택, 동일 버전 재사용, 중단·재개, 429 및 버전 변경 시 데이터 보존을 포함한 회귀 테스트 12개를 추가·정비했습니다.
- Windows 10에서 게임과 함께 실행할 때의 메모리 사용량과 브라우저 표시 동작은 실제 PC 검증이 필요합니다.
