## 변경 사항

- 증강 도감을 추가했습니다. 이름·초성 검색과 등급 필터로 증강을 찾고, 능력 설명과 어울리는 챔피언을 확인할 수 있습니다. 추천 챔피언을 누르면 기존 챔피언 화면으로 이동합니다.
- 요약과 증강 순위에서 증강에 마우스를 올리거나 키보드 초점을 두면 능력 설명을 표시합니다. 설명 데이터는 기존 캐시를 재사용하며 필요한 경우 버튼으로 받습니다.
- 아이템 빌드에서 핵심 조합을 선택하면 해당 조합에 연결된 다음 아이템을 표시합니다. 선택을 해제하면 공통 후속 목록으로 돌아갑니다.
- 공통 후속 목록에서 표시 중인 핵심 조합과 겹치는 아이템을 제외하고, 아이템 빌드 탭의 중복 주문·스킬 정보를 제거했습니다.
- 서버 의존성을 하나의 파일로 묶어 배포본의 node_modules와 npm·npx를 제거했습니다. Node 실행 파일과 필요한 라이선스만 포함하여 압축 해제·삭제 시 파일 수와 불필요한 용량을 줄였습니다. Node를 따로 설치할 필요는 없습니다.
- API 키·설정·캐시는 문서/mayhem-pocket에 유지되므로 앱을 종료한 뒤 기존 배포 폴더를 삭제하고 새 ZIP을 풀어 사용할 수 있습니다. 기존 배포 폴더에 .env 또는 예전 cache가 남아 있다면 먼저 보관해 주세요.

## 검증

- 전체 테스트 35개와 프로덕션 빌드를 통과했습니다.
- node_modules가 없는 별도 한글·공백 경로에서 서버 시작, 화면 파일 및 캐시 조회, 설정 저장, 정상 종료, 재실행과 설정 유지를 검증했습니다.
- 증강 도감과 빌드별 후속 아이템의 실제 화면과 검색·필터·챔피언 이동 동작을 확인했습니다.
- Windows CI에서 ZIP 구성과 GUI 실행·중복 실행·웹 종료·종료.cmd·포트 충돌·강제 종료 정리를 검증한 경우에만 실행 파일을 게시합니다.
- 실제 Windows 10에서 트레이 외관과 기본 브라우저 표시는 별도로 확인해야 합니다.
