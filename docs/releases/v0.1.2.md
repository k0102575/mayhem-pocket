## 변경 사항

### 빠른 검색과 요약

- 공백을 생략한 이름과 초성으로 챔피언을 검색할 수 있도록 개선했습니다.
- 챔피언 목록에 전체 승률 순위 기준 S~D 자체 티어를 표시하고, 승률 숫자는 상세 화면에서만 표시합니다. 검색하거나 즐겨찾기를 바꿔도 티어 기준은 유지됩니다.
- 첫 `빌드` 탭에 소환사 주문 2개 조합, 레벨별 스킬 순서, 추천 증강 TOP 10, 핵심 아이템 조합을 모았습니다.
- 요약 왼쪽에는 사용 빈도 1순위 빌드의 코어 조합 3개, 오른쪽에는 2·3순위 빌드의 첫 조합을 표시합니다.
- 기존 증강 순위·아이템 빌드 탭의 전체 정보와 필터·정렬은 유지하고, 유형별 주문·스킬은 접힌 영역으로 정리했습니다.

### 화면과 사용성

- 스크롤바 유무에 따라 화면이 좌우로 움직이는 현상을 방지했습니다.
- 다크·라이트 전환을 추가하고 선택한 모드를 저장합니다.
- 마지막 다운로드 시각과 최신 여부를 한 곳에 모으고 세부 날짜·출처는 접힌 데이터 정보로 정리했습니다.
- 상세 다운로드 대상과 진행 상태, 완료·실패 안내를 개선하고 중복 오프라인 안내를 제거했습니다.
- 상세 조회와 설정 읽기·저장 실패 시 재시도를 제공하며, 늦게 도착한 초기 설정이 사용자의 변경을 덮지 않도록 했습니다.

### Windows 실행기와 트레이

- 터미널 창 없이 로컬 서버를 시작하는 `Mayhem Pocket.exe`를 추가했습니다.
- 알림 영역에 서버 상태와 화면 열기·로그 폴더 열기·서버 종료 메뉴를 제공합니다.
- 중복 실행 시 기존 서버와 트레이를 재사용하고, 웹 화면에서 종료하면 트레이도 함께 종료합니다.
- 실행기가 시작한 서버는 실행기 강제 종료 시에도 정리되도록 했습니다. 기존에 실행 중이던 서버에 연결한 경우에는 소유하지 않은 프로세스를 임의로 강제 종료하지 않습니다.
- 실행 오류 로그와 이전 실행 기록·사용 중인 포트 복구를 추가했습니다. Node 런타임은 기존과 같이 ZIP에 포함됩니다.

## 검증

- 검색·요약·티어·테마·설정·캐시·서버 수명주기 회귀 테스트 19개를 통과했습니다.
- 저장된 실제 블라디미르 데이터로 화면 구성과 테마 저장, 오류 재시도 및 초기 설정 변경 보호를 검증했습니다.
- Windows CI에서 GUI 실행 파일, 한글·공백 경로, 중복 실행, 각 종료 경로, 포트 충돌, 기존 서버 보호 및 강제 종료 후 서버 정리를 검증했습니다.
- 실제 Windows 10에서 트레이 표시·기본 브라우저 열기와 게임 병행 성능은 실사용 확인이 필요합니다.
