## 변경 사항

### 캐시와 설정 보존

- 캐시·즐겨찾기·최근 조회·화면 설정을 실행 폴더 대신 사용자 문서 폴더의 `mayhem-pocket`에 저장합니다.
- Windows의 실제 문서 경로를 사용하므로 OneDrive로 이동된 문서 폴더도 지원합니다.
- 기존 실행 폴더의 `cache`를 첫 실행 시 자동 복사합니다. 원본은 유지하고 새 저장소의 기존 파일은 덮어쓰지 않습니다.
- 업데이트 폴더가 달라져도 같은 저장소와 트레이 실행 상태를 사용하도록 변경했습니다.

### API 키 등록

- 키가 없으면 화면에서 API 키를 입력하고 바로 사용할 수 있습니다. `.env` 파일을 직접 만들 필요가 없습니다.
- 키는 사용자 문서 폴더에 저장해 다음 실행과 업데이트 후에도 유지합니다.
- 기존 `.env`의 키를 자동으로 가져오며, 데이터 관리에서 키를 변경할 수 있습니다.

### 검색과 다운로드 표시

- 한글 입력기가 `ㄹㅅ`을 `ㄽ`으로 합쳐도 바루스가 검색되도록 개선했습니다. 다른 겹자음과 증강 검색에도 적용됩니다.
- 목록 확인 중 회전 아이콘과 진행 문구를 표시합니다.
- `전체 증강 받기`를 `모든 챔피언 증강 미리 받기`로 변경했습니다.

## 검증

- 캐시 이전·보존, API 키 등록·변경·자동 이전, 겹자음 검색 등을 포함한 테스트 25개와 빌드를 통과했습니다.
- Windows 실행·종료·패키지 검증을 통과한 경우에만 실행 파일을 게시합니다.
