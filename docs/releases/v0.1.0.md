## 첫 공개 버전

무작위 총력전: 아수라장의 증강과 빌드 정보를 검색하는 개인용 로컬 도구 Mayhem Pocket을 공개합니다.

## 주요 기능

- 챔피언 이름·초성 검색, 즐겨찾기와 최근 조회를 지원합니다.
- 챔피언별 증강 추천 순위와 승률, 빌드 정보를 표시하고 필터와 정렬을 제공합니다.
- 챔피언 상세를 개별적으로 다운로드하거나 전체 챔피언의 증강 데이터를 수집할 수 있습니다.
- 데이터와 아이콘을 로컬에 캐시해 반복 조회에 활용합니다.
- 전체 수집의 중단·이어받기와 일일 API 할당량에 따른 수집 제한을 지원합니다.
- 공식 Node.js 런타임을 포함한 Windows ZIP과 실행·종료 스크립트를 제공합니다.
- GitHub Actions에서 테스트·빌드·패키지 검증 후 ZIP과 SHA-256 체크섬을 게시합니다.

## 데이터 및 검증 범위

- ARAMGG의 한국어 API를 사용합니다. 아이템 빌드는 일반 무작위 총력전의 참고 데이터입니다.
- 유효하지 않거나 승리 수·게임 수와 일치하지 않는 승률은 표시하지 않습니다.
- Windows CI에서 테스트, 빌드, 패키지 서버 기동과 종료를 검증했습니다.
- Windows 10에서 게임과 함께 사용할 때의 메모리 사용량은 실제 PC 검증이 필요합니다.
