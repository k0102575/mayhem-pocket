## C# 서버 전환

Node 서버를 C# 내장 서버로 전환했습니다. Windows 기본 .NET Framework를 사용하며 Node·Python·추가 런타임 설치가 필요하지 않습니다. 화면은 기존 구성을 유지합니다.

조회용 시제품에서 지원하지 않았던 다음 기능을 추가했습니다.

- API 키 등록·변경·보관 및 기존 .env 키 가져오기
- 최신 버전 확인, 챔피언 목록·상세·증강 설명 다운로드
- 전체 증강 수집·중단·이어받기와 상세용 20 credits 보존
- 키·UTC 날짜별 사용량 관리, 401·429·실패 안내
- 같은 버전 캐시 재사용 및 수집 중 버전 변경·오류 시 기존 데이터 보존
- 이미지 다운로드·캐시·재다운로드

실행 파일과 서버가 하나의 프로세스에서 동작합니다. 앱을 종료한 뒤 새 ZIP을 다른 폴더에 풀어 실행하세요. 기존 문서/mayhem-pocket의 API 키·캐시·설정을 이어서 사용합니다. 조회용 C# 시제품의 별도 설정 폴더는 사용하지 않습니다. 기존 실행 폴더의 .env·cache가 필요하면 삭제 전에 보관하세요.

## 검증 및 집 PC 확인

Windows CI에서 새 데이터 폴더의 키 등록→목록·도감·상세 다운로드→조회→종료·재실행, 전체 수집·중단·재개, 사용량 제한, 오류와 버전 변경 시 캐시 보존을 테스트 서버로 검증한 뒤 게시합니다. 실제 API 키나 유료 호출은 CI에서 사용하지 않습니다. 별도로 생성한 검증 실행 파일만 loopback 테스트 서버를 사용하며 배포 실행 파일은 실제 제공자 주소로 고정됩니다.

한글·공백 경로, 중복 실행, 포트 충돌, 웹·트레이 종료, 강제 종료 후 재시작도 검사합니다. 실제 집 PC에서 제공자 연결·다운로드와 트레이·브라우저 표시를 다시 확인해 주세요. 문제가 있으면 v0.1.5 Node 배포본으로 돌아갈 수 있으며 캐시는 같은 위치에 유지됩니다.
