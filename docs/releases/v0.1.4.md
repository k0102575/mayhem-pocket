## 변경 사항

- 신발은 빌드 유형별 반복 표시 대신 공통 영역에서 한 번만 표시합니다.
- 빌드 요약과 아이템 빌드에서 신발을 제외하고, 원본 코어 조합에 연결된 후속 아이템으로 핵심 아이템 3개를 구성합니다.
- 연결 데이터가 없으면 해당 빌드 유형의 후속 추천으로 보충하며, 이 경우 조합 승률과 게임 수는 표시하지 않습니다. 아이템 정보가 부족하면 있는 만큼만 표시합니다.
- 같은 아이템 순서의 중복 조합을 제거합니다. 기존 캐시를 사용하며 추가 API 요청은 하지 않습니다.
- 화면 하단 버전 표기를 갱신했습니다.

## 검증

- 검색·캐시·설정·키 등록·신발 분리·후속 조합 연결을 포함한 테스트 27개와 프로덕션 빌드를 통과했습니다.
- 실제 저장된 블라디미르 데이터로 공통 신발과 후속 아이템을 포함한 요약·아이템 빌드 화면을 확인했습니다.
- Windows 실행·종료·패키지 검증을 통과한 경우에만 실행 파일을 게시합니다.
- 실제 Windows 10 실사용 검증은 별도로 필요합니다.
